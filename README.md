## GitHub Pages 建議部署
1. 建立一個 Public repository，例如 `petai-legal`
2. 把本資料夾 5 個網站檔案上傳到 repository 根目錄
3. Repository → Settings → Pages
4. Source 選 `Deploy from a branch`
5. Branch 選 `main`，資料夾選 `/ (root)`，儲存
6. 等待 GitHub Pages 發布

完成後通常會是：
`https://你的GitHub帳號.github.io/petai-legal/`

可用網址：
- 隱私權政策：`.../privacy.html`
- 服務條款：`.../terms.html`
- 帳號刪除：`.../delete-account.html`
